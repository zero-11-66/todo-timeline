      键盘怎么用

      Enter添加当前这句话
      ↑↓输入框空着时，切换选中的待办
      空格勾选完成 / 取消完成
      ShiftDelete删除选中的待办（按两次确认）
      /随时回到输入框

      时间写法：今天 / 明天 / 后天 / 下周三 / 3天后 / 12月5日 / 2026-12-05，后面可跟 下午3点、14:00、晚上8点半；优先级用 !、!!、!!!，或「高」「中」「低」。只写「早餐 / 午饭 / 晚饭 / 夜宵 / 下午茶」也会自动配上钟点，日期不用管。
